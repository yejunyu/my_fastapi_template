# 项目概览
这是一个基于 FastAPI 的 AI 语音面试平台。它利用第三方服务（字节跳动火山引擎）进行实时语音识别（ASR）、语音合成（TTS）和大型语言模型（LLM）驱动的面试交互。用户可以上传简历，系统会根据简历内容进行智能分析，并发起一场模拟面试。面试过程中的对话被实时记录，并在面试结束后生成一份综合评估报告。

# 分析
- `app/api/v1/endpoints/`: 暴露了用户认证、聊天、RTC信令和支付等核心API。
- `app/core/`: 包含配置、安全、中间件等核心应用设置。
- `app/crud/`: 封装了所有数据库表的增删改查操作。
- `app/models/`: 定义了SQLAlchemy数据模型。
- `app/services/`: 包含了业务逻辑，特别是与第三方服务（如邮件、字节跳动RTC）的交互。
- `app/schemas/`: 定义了Pydantic数据校验模型，用于API的请求和响应。
- `prompt/`: 存放了用于驱动AI交互的提示模板。
- 关键流程：用户通过上传简历发起面试 -> 后端调用AI分析简历 -> 生成RTC配置 -> 客户端通过RTC与AI进行语音面试 -> 面试结束后后端调用AI生成评估报告。
